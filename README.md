# The Battery's Last Text to Its Charger

The phone battery's last text to the charger it waited for all day: left on 1% since breakfast while the charger fed the earbuds, the watch, and the toothbrush first — so it spent its last 1% texting goodbye to the group chat.

`main.ts` (Node 22+, stdlib only) writes the single line to
`/output/entry.txt`, with a self-check that it is one non-blank line of
1–200 characters. Run it with `node main.ts`.
